# Build on the existing spreadsheet

**Decision:** the order intake reads the existing form's emails and writes to the existing spreadsheet.

**Why:** the easiest path is the one the client already owns. A new service would mean a new bill, a new login and a new thing to break.

**Revisit if:** order volume outgrows the spreadsheet.
