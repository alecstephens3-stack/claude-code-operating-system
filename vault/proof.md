# Proof of results

Every number here was measured, with the date and the source next to it. `guards/copy_check.py` treats this file as the record: a number in a draft that is not here gets flagged.

## Example Co. (fictional)

- Order entry took 25 minutes per order before the build and 6 minutes after (shop manager's own timing, before and after, two weeks each).
- About 8 hours a week returned to the shop manager across 3 staff (same measurement).
- 0 orders lost to retyping errors in the first month, against 4 in the month before (the shop's order log).
